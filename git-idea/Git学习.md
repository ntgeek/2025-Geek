## 学习内容
### A 下载及布置Git

1.刚开始看见Git的时候就知道肯定是跟GitHub配套使用。先看了[廖雪峰的 Git 教程](https://www.liaoxuefeng.com/wiki/896043488029600)以及B站上的教学视频[给傻子的Git教程]([给傻子的Git教程_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV1Hkr7YYEh8/?spm_id_from=333.1387.favlist.content.click&vd_source=2e665bb499620ff7c35d9d551c1ca19e))

2.下载的时候官网上一直转圈圈，点不动下载按钮。于是找了mirror把Git下下来了，但是下了之后才发现还没有vscode，于是又爬回去    下，下载速度实在是赛蜗牛。
3.下载好这些东西并将编辑器改成vscode后就可以在vscode里面编辑啦。

### B Gitd的使用
1.vscode使用起来还是挺好的，虽然中间出现了上传不了的情况，但后面更换了一个上传仓库就好了（本人出错原因有很多个，比如合并2.冲突、拼写错误、重复上传等等，原理尚在思考中...)
Git Bash操作比较复杂，本人不是很习惯。
3.在仓库中直接上传感觉最方便，目前没感受到弊端。
