## 学习内容

### 初识Git

通过deep seek，我知道Git 是目前世界上最先进的分布式版本控制系统，能自动帮我们记录每次文件的改动，还可以让同伴协作编辑，查看每次的修改内容，这可要比使用一般办公软件的效率高得多。

### Git的使用

看完**廖雪峰的 Git 教程**后，其实我对任务和Git的使用还是不懂，然后我看了bilibili上的视频，开始尝试用Git bash，多次报错，尝试了很多次，也问了ai哪里报错，直到任务截止，也没有通过Git bash推送文档，之后看到第二个，了解到visual studio code，经过学习后发现这个更加方便 ，然后用这个完成了任务，我感觉很神奇，不用操作，只用输入一些指令，就能将文件推送到仓库中，对于这个过程实现的背后十分好奇，然后后面看了小红书上的笔记，了解到了指令后面的操作。
