## 5️⃣ 了解更多语言的魅力 —— CSS 3 和 JavaScript

**推荐阶段时长：`7` 天**

💡Tip：
本阶段主要围绕 Web 页面布局能力与 JavaScript 基础语法，进一步加深对前端语言本身的理解
思考页面是如何被“控制”的？

### 🛒 学习内容

**CSS 3**

- ⭐**响应式布局**
- 媒体查询
- Flex 布局
- Grid 布局

**JavaScript**

- 函数
  - ⭐**自定义函数**
  - 函数调用方式
    - ⭐**全局调用**
    - 构造函数调用
    - ⭐**函数方法调用**
    - apply
    - call
  - 闭包
  - 作用域（作用域链）
  - 深挖JS更多语法
    - 正则表达式
    - 错误
    - 事件
- 严格模式
- JSON
- ⭐**DOM API**
- 性能优化
  - 防抖
  - 节流
- Ajax
- ES6
  - let / const
  - ⭐**Promise & async / await 异步编程**
- 使用 JavaScript 实现 Web 端调试

### 📑 实践内容

-  [ ] 不限题材，根据上述所学内容写一个只使用JS语言的小网页(必做)
-  [ ] 每一个知识点尽量产出对应demo(选做)和笔记(选做)
-  [ ] 根据理解的防抖和节流知识产出一个demo(必做)
-  [ ] 深挖js中document.write()并产出理解笔记(选做)

### 💭 额外思考内容（选做）

- 你在小网页里用了哪些 DOM 操作？有没有更“规范/更现代”的替代方式？
- 防抖和节流分别适合哪些交互场景？有没有你觉得“看起来该用，但实际没必要用”的场景？
- `document.write()` 为什么在现代开发中不推荐？如果必须实现“动态插入内容”，你认为该怎么做？
- 你写的 Demo 里，哪些行为属于“同步”，哪些属于“异步”？你是怎么判断的？

## 6️⃣ 巩固基础 —— 依托知识

**推荐阶段时长：`7` 天**

💡Tip：
本阶段主要了解前端开发所依托的计算机基础与Web基础，以免前端开发正式开始学习时云里雾里~

### 🛒 学习内容

**计算机基础**

- TCP / IP 初识，此阶段暂时不需要学的太深入
  - TCP 的特点
  - TCP 报文结构
  - TCP 建立连接与释放连接的过程
- HTTP 初识，此阶段暂时不需要学的太深入
  - 报文结构
  - 状态码含义
  - 完整的 HTTP 请求 / 响应流程

**Web基础**

- 互联网
- ⭐域名
- ⭐DNS
- 服务器
- 浏览器
  - DOM 事件流
  - 事件委托
  - ⭐浏览器加载过程
  - ⭐浏览器渲染过程
  - 事件循环
  - Headless Browser
  - WebView

### 📑 实践内容

-  [ ] 针对学习到的知识点产出对应demo和笔记（选做）

### 💭 额外思考内容（选做）

- 一次打开网页的过程中，哪些环节是“网络层”的问题，哪些是“浏览器渲染层”的问题？
- DNS 的存在解决了什么问题？如果没有 DNS，用户体验会变成什么样？
- 事件委托为什么能减少事件监听数量？它的代价是什么？
- 事件循环和“异步”之间的关系是什么？你能举一个页面卡顿可能出现的原因吗？

## 7️⃣ Web 前端框架 —— Vue

**推荐阶段时长：`10` 天**

💡Tip：本阶段主要了解并使用 Web 前端框架 —— Vue，尝试通过框架组织页面结构。

### 🛒 学习内容

**前端框架的认识**

- Web 前端框架的概念

**Vue学习**

- Vue 的基本认识

- Vue 开发环境的安装

- Vue 文件的基本模板

  > 尝试自己创建一个vue文件的模板，就类似在vscode中打出一个！自动加载前端基本框架

- 学会如何创建一个vue项目并且使用命令行唤醒网页

- 粗浅了解一下Vuex

- 了解一下vue引用组件库用法

### 📑 实践内容

-  [ ] 创建一个 **包含两个页面的小网站（必做）**
  - 页面一：用户注册登录页面
  - 页面二：自由设计
  - 实现两个页面之间的流畅切换

### 💭 额外思考内容（选做）

- 你的小网站里，哪些部分适合拆成组件？拆分的依据是什么？
- Vue 的“响应式”在你的项目里体现在哪？它和你在原生 JS 里操作 DOM 的方式有什么不同？
- 如果不用 Vuex，你会如何在两个页面之间共享状态？有没有遇到“状态乱了”的情况？
- 你认为“框架”解决了你哪些痛点？有没有引入新的复杂度？

### 🔗 参考资料

- [Vue官方文档](https://cn.vuejs.org/guide/introduction)——Vue官网
- [VueSFC Playground](https://play.vuejs.org/)——Vue官方演练场
