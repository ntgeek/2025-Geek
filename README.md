## 🚩 注意事项

> 和前中期的考核方式会有所不同💡
> 希望大家在寒假期间，学会如何独立地推进一项技术任务

### 1️⃣ 各阶段 task 的流程的调整

1. 先想清楚目标，再开始动手：

   我们提供的各阶段时长仅作参考，
   在正式开始某个 task 前，**如果你有精力**，可以尝试：

   * 简单规划一下该 task 的完成时间

   * 思考一下自己的推进方式或学习安排

   * 并将你的想法私下发给对应的 mentor，

     > 他/她可能会给你一些额外的参考资料 or 修改建议

2. 从“等待检查”转为“主动沟通”

   请尽量依次完成 task 中的各项要求，
   更推荐每完成某一阶段或某一部分内容后，
   主动联系 mentor 检查你的完成情况

   > 这样他/她可以及时地了解到你的进展，也可以提供些建议与帮助

### 2️⃣允许使用 AI ,但请不要过度依赖

本阶段**允许使用 AI 工具辅助学习与解决问题**，
但请尽量避免完全依赖或直接照搬结果。

我们更关注的是：

- 你是否理解了过程
- 是否能解释自己的实现与选择
- 是否能在总结中体现你的思考

### 3️⃣ 各阶段任务的小总结

在完成每个阶段任务后，**请写一份简短的小总结**，

内容可以包括但不限于：

- 遇到的问题与解决过程
- 踩过的坑或新的收获
- 对当前任务的反思与改进想法

* *如果在某些关键问题上借助了 AI*，
  *也欢迎在总结中简单记录你的使用方式与理解过程*

> 形式或篇幅也不限，我们更看重真实记录与思考过程
