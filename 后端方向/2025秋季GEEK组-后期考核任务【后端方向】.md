## :five: 阶段五【万法同源，先学一法 —— Golang】

推荐阶段时长：`5`天

### 📌前置：Linux 环境快速上手

> 在正式开始 Go 学习前，
> 本阶段会先简单接触 Linux 常用的一部分命令，
> 方便后面在虚拟机中进行开发，
> 仅需掌握后端开发中最常用的即可

* 目录与文件操作
  * ls / cd / pwd
  * mkdir / rm 
  * touch / cat 

* 权限与执行
  * chmod
  * sudo

* 网络与端口（了解即可）
  
  * ping
  
  * netstat
  
* 进程与服务（了解即可）
  * ps
  * systemctl
  
* 调试与日志查看
  * curl
  * tail（如 tail -f 查看日志）

### :shopping_cart: 学习内容

* Go 语言初识

  * Go 前世今生	

  * Go 主要应用场景

  * Go 的执行原理（优先了解 Go 命令相关内容）

* Go 开发环境准备

  * 搭建 Linux 虚拟机作为开发环境，配置为 Go 依赖环境

  * 本地通过 remote-ssh 连接虚拟机，两种可考虑方案如下：

    * 内网穿透

    * 虚拟机开 NAT 模式

      > 本地是否配置 Go 环境不作要求，鼓励体验真实服务端环境

* Go 的基础语法（快速回顾）

  > 该部分不追求语法的全面性，而是为后续阶段打基础

### 📑任务目标

* 根据本阶段所学内容，完成一个 console 的程序作为 demo，
  题材不限，并为你的 Go 程序编写一份简短的 README，
  说明：程序是干什么的？有哪些功能？怎么操作？它使用了哪些 Go 知识点？

  - session

### 📑任务目标

- 使用 Gin + Gorm 实现成员管理系统的后端接口：（有时间可以进行拓展~）

  - 用户包括 —— 管理员和普通用户

  - 用户注册和登录

    用户信息包括用户ID、密码（数据库中加密）、昵称、手机号、邮箱地址

  - 管理员

    - 删除普通用户
    - 获取一个成员信息
    - 获取所有成员信息
    - 审核新用户注册信息

  - 普通用户

    - 更改个人信息
  
- 编写一份接口实现编后感。说说：

  * 这个后端系统你最初是怎么规划的？
    你最终实现的效果和你的最初预期有哪些差异？

    * 在项目中，你是怎么组织代码结构的？  
      各个模块（路由 / 业务逻辑 / 数据访问等）分别承担什么职责？

    * 你是如何设计接口的？  
      在使用 RESTful API 过程中，有没有遇到设计上的困惑？

    * 在项目开发过程中，你遇到的**最大困难**是什么？  
      你是如何定位问题、查资料并最终解决的？

    * 你认为当前项目还存在哪些不足？  
      如果将来你有更多的时间，你会优先从哪些方面对该项目进行优化？
